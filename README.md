# Bonjour — 나의 작은 프랑스어 교실

사이트: https://yeonsungai29-gif.github.io/bonjour-french/

한국어 사용자를 위한 프랑스어 A1 입문 사이트입니다. 설치나 빌드 없이 `index.html`을 브라우저에서 열어 사용할 수 있습니다.

## 학습 기능

- **주제별 단어 40개**: 인사, 기본 표현, 음식, 일상, 동물, 자연, 숫자, 여행. 뜻·예문·음성·암기 기록 제공.
- **기초 회화 6개**: 상황별 표현과 한국어 설명, 발음 듣기.
- **단어 퀴즈**: 매번 무작위 5문제, 정답 안내와 누적 정답률.
- **오답 복습**: 단어·듣기 퀴즈 오답을 저장합니다. 오답 퀴즈를 맞히면 해당 단어가 목록에서 빠집니다. 틀린 단어는 다음 날에도 유지됩니다.
- **기초 문법 5단원**: 성별과 부정관사, 정관사, être, avoir, 기본 어순과 부정문. 각 단원에 연습 문제와 해설이 있습니다. 문법 문제는 오답 단어 목록에는 추가하지 않습니다.
- **듣기 퀴즈**: 재생 버튼으로 프랑스어를 듣고 한국어 뜻을 선택합니다. 정답 제출 전에는 프랑스어 철자를 숨깁니다.
- **하루 목표**: 서로 다른 단어 5개 복습 + 문제 5개 풀이. 단어의 뜻을 확인하거나 ‘외웠어요’를 누르면 복습에 반영합니다. 이미 외운 단어도 다음 날 다시 복습할 수 있습니다. 단어·듣기·문법·오답 문제 풀이가 목표에 합산됩니다.

## 기록과 음성

기록은 동일 기기·브라우저의 localStorage에 저장되며 계정이나 서버와 동기화되지 않습니다. 기존 버전의 암기·퀴즈 기록을 유지합니다. 하루 목표는 기기의 현지 날짜 기준으로 새로 집계하고 이전 오답은 유지합니다. 저장이 차단되면 현재 페이지에서만 기록을 유지합니다.

발음은 Web Speech API를 사용합니다. 기기의 프랑스어 음성과 브라우저 지원에 따라 재생 여부와 품질이 다릅니다. 음성 재생이 안 되면 기기의 프랑스어 음성 설정과 네트워크를 확인하세요.

## GitHub Pages

저장소 **Settings → Pages**에서 **Deploy from a branch → main → /(root)**를 선택합니다. `index.html`, `app.js`, `.nojekyll`을 저장소 최상위에 두고 변경 내용을 커밋하면 자동 배포됩니다.

## 내용 수정

단어·회화·문법 자료는 `app.js`, 화면과 디자인은 `index.html`에 있습니다. 기존 단어의 배열 순서는 학습 기록과 연결되므로 유지하고 새 단어는 뒤에 추가하세요. 단어 수 변경 시 화면의 총 단어 수 표시도 수정하세요.

외부 라이브러리, API 키, 회원가입이 필요하지 않습니다.

## 실생활 학습 여정

홈 화면은 파란색·크림색을 사용한 상황별 학습 지도입니다. 자유 연습실에서 기존 단어·회화·문법·오답·듣기 기능을 사용할 수 있습니다.

8개 상황: 첫 만남 → 카페 → 마트 → 길·교통 → 숙소 → 식당 → 몸이 아플 때 → 도움 요청.

각 수업은 핵심 표현 3개를 먼저 보여주고 뜻 선택·듣기·문장 조립으로 구성된 기본 5문제를 제공합니다. 틀린 문제는 대기열 뒤에 추가되며, 모두 맞혀야 수업이 완료되고 다음 수업이 열립니다. 수업 안의 오답은 그 수업에서 재도전하며 자유 연습실의 단어 오답 목록과는 별개입니다. 음성을 사용할 수 없으면 ‘소리 대신 글로 보기’로 읽기 문제를 풀 수 있습니다.

첫 수업 완료는 20 XP, 완료한 수업을 다시 끝내면 5 XP를 받습니다. 연속 학습은 기기의 현지 날짜 기준으로 수업을 완료한 날을 셉니다. 오늘 아직 수업을 마치지 않았다면 어제까지 이어진 연속 기록을 표시합니다. 중간에 나가면 그 수업의 문제 순서·진행은 저장하지 않으며, 이미 제출한 문제 풀이 기록은 유지합니다. 기존 브라우저 학습 기록을 그대로 사용합니다.

학습 지도·수업 내용과 진행 처리는 `journey.js`, 공통 디자인은 `style.css`에 있습니다. 전체 파일은 `index.html`, `app.js`, `journey.js`, `style.css`, `.nojekyll`입니다.

## 실전 대화 · 누적 복습 · 백업

상단 **실전 대화**에서 다음 기능을 이용할 수 있습니다.

- **역할극 8개**: 상황마다 상대의 질문 3차례에 답하는 선택형 대화입니다. 상대의 말 듣기와 뜻 보기, 정답 해설과 답변 듣기를 제공합니다. 틀린 차례는 맞힐 때까지 재도전합니다.
- **표현 바꿔 말하기 16문제**: 제시된 문장 틀에서 물건·수량·장소·이름·증상을 바꾸어 직접 입력합니다. 정해진 문장 틀을 연습하는 채점이며 자유 대화의 모든 가능한 답변을 평가하지는 않습니다. 대소문자·악센트·문장부호 차이는 허용하며 정답의 표준 표기를 표시합니다.
- **누적 복습**: 완료한 수업에서 최대 5개 표현을 섞어 출제하고, 학습 수업이나 누적 복습에서 틀렸던 표현을 우선합니다. 정답을 맞히면 해당 표현은 우선 복습 목록에서 빠집니다. 두 번째 학습 수업부터는 기본 5문제에 이전 수업 복습 1문제도 포함됩니다.
- **프랑스 생활 팁 8개**: 각 상황 카드의 접이식 항목에서 말투·주문·교통·숙소 이용 등의 맥락을 확인합니다.
- **백업·복원**: JSON 파일을 내려받아 보관하고 다른 브라우저에서 복원할 수 있습니다. 파일 형식·버전·날짜·문제 수·학습 단계 등을 검사하며 1MB를 초과한 파일은 받지 않습니다. 복원 전 확인을 거친 뒤 현재 기록을 교체합니다. 복원할 기기의 기존 기록도 먼저 백업해 두세요.

실전 대화의 문제 풀이도 전체 정답률과 하루 문제 풀이 목표에 합산됩니다. 역할극·표현 바꾸기의 완료 상태는 저장합니다. XP와 연속 수업 기록은 학습 지도 수업 완료로 쌓으며 실전 연습 완료에는 별도로 부여하지 않습니다. 진행 중인 대화나 입력 내용은 백업에 포함되지 않고 완료·풀이 기록만 포함됩니다.

실전 자료와 백업 처리는 `practice.js`에 있습니다. 배포할 파일에 `practice.js`도 포함하세요. 업로드된 백업을 외부 서버로 전송하지 않고 브라우저 안에서 읽습니다.
