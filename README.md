# Bonjour — 나의 작은 프랑스어 교실

사이트: https://yeonsungai29-gif.github.io/bonjour-french/

한국어 사용자를 위한 프랑스어 A1 입문 사이트입니다. 설치나 빌드 없이 `index.html`을 브라우저에서 열어 사용할 수 있습니다.

## 학습 기능

- **주제별 단어 40개**: 인사, 기본 표현, 음식, 일상, 동물, 자연, 숫자, 여행. 뜻·예문·음성·암기 기록 제공.
- **기초 회화 6개**: 상황별 표현과 한국어 설명, 발음 듣기.
- **단어 퀴즈**: 매번 무작위 5문제, 정답 안내와 누적 정답률.
- **오답 복습**: 단어·듣기 퀴즈 오답을 저장합니다. 오답 퀴즈를 맞히면 해당 단어가 목록에서 빠집니다. 틀린 단어는 다음 날에도 유지됩니다.
- **기초 문법 5단원**: 성별과 부정관사, 정관사, être, avoir, 기본 어순과 부정문. 각 단원에 연습 문제와 해설이 있습니다. 문법 문제는 오답 단어 목록에는 추가하지 않습니다.
- **듣기 퀴즈**: 재생 버튼으로 프랑스어를 듣고 한국어 뜻을 선택합니다. 정답 제출 전에는 프랑스어 철자를 숨깁니다.
- **하루 목표**: 서로 다른 단어 5개 복습 + 문제 5개 풀이. 단어의 뜻을 확인하거나 ‘외웠어요’를 누르면 복습에 반영합니다. 이미 외운 단어도 다음 날 다시 복습할 수 있습니다. 단어·듣기·문법·오답 문제 풀이가 목표에 합산됩니다.

## 기록과 음성

기록은 동일 기기·브라우저의 localStorage에 저장되며 계정이나 서버와 동기화되지 않습니다. 기존 버전의 암기·퀴즈 기록을 유지합니다. 하루 목표는 기기의 현지 날짜 기준으로 새로 집계하고 이전 오답은 유지합니다. 저장이 차단되면 현재 페이지에서만 기록을 유지합니다.

발음은 Web Speech API를 사용합니다. 기기의 프랑스어 음성과 브라우저 지원에 따라 재생 여부와 품질이 다릅니다. 음성 재생이 안 되면 기기의 프랑스어 음성 설정과 네트워크를 확인하세요.

## GitHub Pages

저장소 **Settings → Pages**에서 **Deploy from a branch → main → /(root)**를 선택합니다. `index.html`, `app.js`, `.nojekyll`을 저장소 최상위에 두고 변경 내용을 커밋하면 자동 배포됩니다.

## 내용 수정

단어·회화·문법 자료는 `app.js`, 화면과 디자인은 `index.html`에 있습니다. 기존 단어의 배열 순서는 학습 기록과 연결되므로 유지하고 새 단어는 뒤에 추가하세요. 단어 수 변경 시 화면의 총 단어 수 표시도 수정하세요.

외부 라이브러리, API 키, 회원가입이 필요하지 않습니다.

## 실생활 학습 여정

홈 화면은 파란색·크림색을 사용한 상황별 학습 지도입니다. 자유 연습실에서 기존 단어·회화·문법·오답·듣기 기능을 사용할 수 있습니다.

8개 상황: 첫 만남 → 카페 → 마트 → 길·교통 → 숙소 → 식당 → 몸이 아플 때 → 도움 요청.

각 수업은 핵심 표현 3개를 먼저 보여주고 뜻 선택·듣기·문장 조립으로 구성된 기본 5문제를 제공합니다. 틀린 문제는 대기열 뒤에 추가되며, 모두 맞혀야 수업이 완료되고 다음 수업이 열립니다. 수업 안의 오답은 그 수업에서 재도전하며 자유 연습실의 단어 오답 목록과는 별개입니다. 음성을 사용할 수 없으면 ‘소리 대신 글로 보기’로 읽기 문제를 풀 수 있습니다.

첫 수업 완료는 20 XP, 완료한 수업을 다시 끝내면 5 XP를 받습니다. 연속 학습은 기기의 현지 날짜 기준으로 수업을 완료한 날을 셉니다. 오늘 아직 수업을 마치지 않았다면 어제까지 이어진 연속 기록을 표시합니다. 실생활 수업은 중간에 나가도 문제 풀이 단계부터 이어서 학습할 수 있습니다. 역할극과 시험 연습은 이미 제출한 풀이 기록을 유지하며 해당 연습은 처음부터 다시 시작합니다. 기존 브라우저 학습 기록을 그대로 사용합니다.

학습 지도·수업 내용과 진행 처리는 `journey.js`, 공통 디자인은 `style.css`에 있습니다. 전체 파일은 `index.html`, `app.js`, `journey.js`, `style.css`, `.nojekyll`입니다.

## 실전 대화 · 누적 복습 · 백업

상단 **실전 대화**에서 다음 기능을 이용할 수 있습니다.

- **역할극 8개**: 상황마다 상대의 질문 3차례에 답하는 선택형 대화입니다. 상대의 말 듣기와 뜻 보기, 정답 해설과 답변 듣기를 제공합니다. 틀린 차례는 맞힐 때까지 재도전합니다.
- **표현 바꿔 말하기 16문제**: 제시된 문장 틀에서 물건·수량·장소·이름·증상을 바꾸어 직접 입력합니다. 정해진 문장 틀을 연습하는 채점이며 자유 대화의 모든 가능한 답변을 평가하지는 않습니다. 대소문자·악센트·문장부호 차이는 허용하며 정답의 표준 표기를 표시합니다.
- **누적 복습**: 완료한 수업에서 최대 5개 표현을 섞어 출제하고, 학습 수업이나 누적 복습에서 틀렸던 표현을 우선합니다. 정답을 맞히면 해당 표현은 우선 복습 목록에서 빠집니다. 두 번째 학습 수업부터는 기본 5문제에 이전 수업 복습 1문제도 포함됩니다.
- **프랑스 생활 팁 8개**: 각 상황 카드의 접이식 항목에서 말투·주문·교통·숙소 이용 등의 맥락을 확인합니다.
- **백업·복원**: JSON 파일을 내려받아 보관하고 다른 브라우저에서 복원할 수 있습니다. 파일 형식·버전·날짜·문제 수·학습 단계 등을 검사하며 1MB를 초과한 파일은 받지 않습니다. 복원 전 확인을 거친 뒤 현재 기록을 교체합니다. 복원할 기기의 기존 기록도 먼저 백업해 두세요.

실전 대화의 문제 풀이도 전체 정답률과 하루 문제 풀이 목표에 합산됩니다. 역할극·표현 바꾸기의 완료 상태는 저장합니다. XP와 연속 수업 기록은 학습 지도 수업 완료로 쌓으며 실전 연습 완료에는 별도로 부여하지 않습니다. 진행 중인 역할극의 입력 내용은 백업에 포함되지 않습니다. 실생활 수업의 자동 저장된 문제 진행과 완료·풀이 기록은 백업에 포함됩니다.

실전 자료와 백업 처리는 `practice.js`에 있습니다. 배포할 파일에 `practice.js`도 포함하세요. 업로드된 백업을 외부 서버로 전송하지 않고 브라우저 안에서 읽습니다.

## 계정별 저장과 학습 방향

헤더의 로그인 버튼에서 이메일·비밀번호 가입/로그인, 비밀번호 재설정, 로그아웃을 이용합니다. 가입 확인·비밀번호 재설정 링크는 **요청을 시작한 동일 브라우저**에서 열어야 합니다(PKCE).

로그인 후 방향을 선택합니다. **실생활 회화**는 기존 8개 상황 여정을, **시험 준비 · A1 기초**는 문법·독해·듣기·문장 연결 4개 연습을 보여줍니다. 각 시험 단원은 회차별로 출제된 5문제를 모두 맞히면 완료되며 첫 완료 +20 XP, 재완료 +5 XP입니다. 공식 DELF 모의시험이나 등급 판정이 아닙니다. 상단 방향 버튼으로 변경하며 두 진도는 별도 보관됩니다.

방문자 학습은 기존 브라우저 기록을 계속 사용합니다. 로그인한 새 계정에는 방문자 기록을 자동 복사하지 않습니다. 내 계정의 **방문자 학습 기록 가져오기**를 선택하면 확인 후 계정 기록을 교체할 수 있습니다. 각 계정은 별도의 브라우저 캐시와 Supabase 레코드를 사용합니다.

### 운영 전 필요한 Supabase 설정

프로젝트: `vmusqtabvssfenozhvzc` (서울)

1. Authentication → URL Configuration의 **Site URL**을 `https://yeonsungai29-gif.github.io/bonjour-french/`로 지정하세요. **Redirect URLs**에도 같은 주소를 추가하세요.
2. Authentication → Email → SMTP Settings에서 발신 메일 서비스를 연결하세요. 기본 SMTP는 프로젝트 팀원 주소에만 메일을 보낼 수 있어 일반 방문자의 가입 확인·재설정 메일에 사용할 수 없습니다. 이메일 확인을 끄지 말고 메일 발송 서비스를 설정하세요.
3. 이메일 확인을 켠 상태로 이메일·비밀번호 가입을 허용하세요. 실제 가입 확인 메일과 재설정 메일이 사이트로 돌아오는지 확인하세요.

프로젝트에는 `supabase/schema.sql`의 테이블·정책·저장 함수가 적용돼 있습니다. 사용자 자신의 행만 읽고 수정할 수 있는 RLS와 비회원 접근 차단을 사용합니다. 기록 버전을 비교하여 다른 기기의 수정 내용을 무조건 덮어쓰지 않습니다. 충돌 시 현재 기록을 백업한 뒤 서버 기록을 불러와야 합니다.

설정 파일 `config.js`에는 공개용 URL과 publishable key만 넣습니다. **service_role, secret key, 관리 토큰, SMTP 비밀번호를 GitHub에 올리지 마세요.** 공식 Supabase 브라우저 SDK 2.119.0을 `vendor/supabase.js`에 고정 버전으로 포함했고 라이선스도 함께 보관합니다.

계정 저장에 실패하면 현재 기기에 저장 대기 데이터를 보관하고 상태를 표시합니다. 네트워크 복구 후 재시도하며 저장 대기 중에는 일반 로그아웃을 막아 데이터 손실을 방지합니다. 다른 기기의 데이터와 충돌하면 자동 덮어쓰기를 중단합니다.

`account.js`가 로그인·저장·학습 방향과 시험 연습을 담당합니다. 배포 파일에 `account.js`, `config.js`, `vendor/supabase.js`, `vendor/LICENSE-supabase`를 포함하세요. 비밀번호는 Supabase Auth에 직접 전송하며 학습 기록·백업 파일에는 포함하지 않습니다.


## 학습 편의 기능

- **오늘의 추천**: 실생활 수업 이어하기, 약한 표현 복습, 선택한 학습 방향의 다음 수업을 안내합니다.
- **실생활 수업 이어하기**: 핵심 표현 화면과 문제 제출 단계에서 자동 저장합니다. 미제출한 선택·조립 상태는 다시 선택하고, 이미 제출한 문제부터 재개합니다. 마지막 문제 후 결과 확인 전에도 재개할 수 있으며 완료 보상을 중복 지급하지 않습니다. 다른 수업으로 바꾸면 기존 중간 진행을 교체하기 전에 확인합니다.
- **표현 노트**: 핵심 표현 24개를 한국어·프랑스어·상황으로 검색하고 저장합니다. 검색은 프랑스어 악센트 차이를 허용하며 상황별·저장한 표현만 보기 필터도 제공합니다.
- **나의 기록**: 실생활·시험 단원 완료 수, 저장 표현, XP, 최근 7일 문제 제출 횟수를 표시합니다. 날짜는 기기 현지 기준이며, 문제 수를 학습 시간으로 환산하지 않습니다.
- **발음 속도**: 아주 천천히·천천히·보통 중 선택하면 전체 듣기에 적용됩니다.
- **악센트 입력**: 표현 바꾸기 입력란 아래의 프랑스어 문자 버튼으로 커서 위치에 문자를 넣습니다.
- **연결 상태 안내**: 인터넷이 끊기면 기기 저장 상태와 계정 저장·음성 이용 제한을 안내합니다. 전체 사이트의 오프라인 실행을 보장하는 기능은 아닙니다.

새 기록은 `study` 항목에 포함되며 계정별 저장과 백업·복원에 함께 반영됩니다. 이전 백업도 계속 가져올 수 있습니다. 기능 코드는 `study.js`에 있고 이 파일을 함께 배포해야 합니다.

현재 `config.js`의 `emailSignupReady`는 `false`입니다. 위의 URL·SMTP 설정을 마치고 실제 인증 메일의 복귀를 확인한 뒤 `true`로 바꾸어야 신규 가입과 비밀번호 재설정을 공개할 수 있습니다. 이 설정을 바꾸지 않은 상태에서 회원가입이 활성화됐다고 안내하지 마세요.


## 간격 복습과 확장된 시험 연습

- 표현의 첫 정답은 다음 날 복습으로 예약합니다. 예정일 이후 정답을 맞히면 3일 뒤, 그다음에는 7일 뒤로 예약하며 이후에는 7일 간격을 유지합니다. 예정일 전 추가 정답으로 간격을 빠르게 늘리지 않습니다.
- 틀리면 간격을 초기화하고 당일 복습 목록으로 돌립니다. 재도전 정답 후 다음 날부터 다시 시작합니다. 완료한 실생활 수업의 표현만 누적 복습 대상으로 표시합니다. 과거 기록에 표현별 복습 날짜가 없으면 새 버전 첫 이용일 기준으로 첫 간격을 시작합니다.
- 시험 기초 문제는 문법·독해·듣기·문장/상황 연결 각 12개, 총 48개입니다. 한 회차에는 중복 없는 5문제를 출제합니다. 영역별 오답, 아직 풀지 않은 문제, 직전 회차와 다른 문제를 우선합니다.
- 영역별 정답률·풀이 수·남은 오답은 **나의 기록**에서 확인합니다. 영역별 통계 추가 이전의 기록을 임의로 소급 계산하지 않습니다. 공식 시험 성적이나 등급 판정이 아닙니다.
- 입력형 표현 바꾸기에서는 기본 답안 외에 일부 자연스러운 요청/위치 질문도 정답으로 인정합니다. 자유로운 모든 표현을 평가하는 방식은 아닙니다. 표준 답안과 악센트를 함께 보여줍니다.

간격과 영역별 기록은 `learning` 항목에 저장하며 계정 동기화·백업에도 포함됩니다. 문제 은행과 간격 알고리즘은 `learning.js`에 있습니다. 이 파일을 배포 목록에 포함해야 합니다.

검증 범위: 코드 수준의 문제 풀이·일정·저장/복원·계정별 분리 점검과 공개 파일 배포 확인입니다. 실제 휴대폰 브라우저의 화면/음성/메일 링크 흐름은 별도 확인이 필요합니다. 회원가입의 URL·SMTP 설정과 `emailSignupReady` 활성화 조건은 위 운영 안내를 따릅니다.
