# Bonjour — 나의 작은 프랑스어 교실

한국어 사용자를 위한 프랑스어 A1 입문 사이트입니다. 설치나 빌드가 필요 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 발음 듣기는 브라우저 및 기기에 설치된 프랑스어 음성 지원에 따라 다릅니다. 프랑스어 음성이 없으면 기기에서 추가해야 할 수 있습니다.

- 단어 16개: 뜻, 예문, 발음 듣기, 외운 단어 기록
- 기초 회화 6개: 한국어 설명과 발음 듣기
- 퀴즈: 5문제씩 무작위 출제, 정답 해설, 누적 정답률
- 학습 기록: 동일 브라우저의 localStorage에 저장, 다른 기기와 동기화하지 않음
- 모바일 화면, 키보드 탭 이동 및 화살표 탭 탐색 지원

## GitHub Pages에 올리기

1. GitHub에 로그인한 뒤 새 **Public** 저장소를 만드세요. 예: `bonjour-french`.
2. 저장소의 **Add file → Upload files**에서 이 폴더 안의 `index.html`, `app.js`, `.nojekyll`을 저장소 최상위에 업로드하고 커밋하세요. README.md도 함께 올려도 됩니다. ZIP 파일 자체를 올리는 것이 아닙니다.
3. 저장소의 **Settings → Pages**로 이동하세요.
4. **Source**를 **Deploy from a branch**로 선택하세요.
5. 브랜치를 **main**, 폴더를 **/(root)**로 선택하고 **Save**를 누르세요.
6. 배포가 완료되면 Pages 설정 화면에 표시된 주소로 접속하세요. 일반적인 주소 형식은 `https://사용자이름.github.io/bonjour-french/`입니다.

파일을 수정하고 다시 커밋하면 GitHub Pages에 반영됩니다. 실제 GitHub 저장소 생성 및 배포는 아직 수행하지 않았습니다.

## 내용 수정

`app.js`의 `words` 배열에서 단어를, `phrases` 배열에서 회화를 수정할 수 있습니다. 디자인은 `index.html` 안의 `<style>`에서 수정합니다. 현재 단어 수는 16개로 표시되므로 개수를 바꾸면 표시 문구도 수정하세요.

외부 라이브러리, API 키, 회원가입, 유료 서비스가 필요하지 않습니다. 음성 재생은 기기에 따라 네트워크를 사용할 수 있습니다.
