# 확장 학습 자료의 출처와 이용 조건

추가 단어와 회화 예문은 언어별로 각각 1,200개입니다. 기존 직접 작성한 수업·40개 단어는 별도 유지합니다. 단순 숫자·이름 치환으로 개수를 늘리지 않았습니다. 이 자료집은 기초부터 일반 표현까지 포함하며 공식 CEFR/JLPT 등급 또는 전수 원어민 검수 자료로 표시하지 않습니다.

## 단어: 한국어 위키낱말사전 / Kaikki.org

- 원출처: https://ko.wiktionary.org/
- 기여자: 각 표제어 페이지의 수정 이력에 있는 위키낱말사전 기여자들. 자료실 각 단어의 ‘기여자·수정 이력’ 링크에서 확인할 수 있습니다.
- 추출: Kaikki.org의 Korean Wiktionary edition / Wiktextract.
- https://kaikki.org/kowiktionary/
- 프랑스어: https://kaikki.org/kowiktionary/프랑스어/
- 일본어: https://kaikki.org/kowiktionary/일본어/
- 라이선스: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0), https://creativecommons.org/licenses/by-sa/4.0/

대표 뜻을 선별하고, 일부 괄호 설명·위키 문법·활용형 참조를 생략하거나 공백을 정리했습니다. 해당 파생 단어 데이터도 CC BY-SA 4.0으로 제공합니다. 품사와 복수 의미를 가능한 범위에서 함께 표시하지만, 모든 문맥의 의미를 보장하는 사전 전체를 대체하지는 않습니다.

빈도 기반 선별에는 wordfreq를 보조적으로 이용했습니다. 빈도 자체나 공식 학습 등급을 공개 자료로 재배포하지 않습니다. wordfreq 프로젝트: https://github.com/rspeer/wordfreq

## 회화 표현·예문: Tatoeba

- 원출처: https://tatoeba.org/
- 공식 다운로드: https://tatoeba.org/ko/downloads
- 라이선스: Creative Commons Attribution 2.0 France (CC BY 2.0 FR), https://creativecommons.org/licenses/by/2.0/fr/
- 각 원문과 한국어 번역의 문장 ID 및 기여자 이름을 데이터에 보관하고, 자료실에서 두 원문 페이지를 각각 연결합니다.

프랑스어–한국어와 일본어–한국어의 직접 번역 링크만 사용했습니다. 다른 언어를 거쳐 새 번역을 만들지 않았습니다. 텍스트 공백·유니코드 표기를 정리하고 중복·긴 문장·일부 부적절한 소재를 제외했습니다. 표현은 반말과 존댓말, 여러 사용 맥락을 포함하므로 원문과 상황을 함께 확인하세요. 모든 항목이 두 사람의 여러 차례 대화로 구성된 역할극은 아니며, 개별 회화 표현·번역 예문입니다.

## 일본어 읽기

사전에서 제공한 가나·루비를 우선 사용했습니다. 그 외 읽기는 Fugashi/UniDic-lite와 pykakasi를 이용해 자동 변환하고 ‘자동 참고’로 표시합니다. 고유명사·다의 한자의 문맥별 읽기는 다를 수 있습니다. 기기의 일본어 음성과 원문도 함께 확인하세요.

- https://github.com/polm/fugashi
- https://github.com/polm/unidic-lite
- https://github.com/miurahr/pykakasi

## 스냅샷과 변경

다운로드 URL·개수·파일 체크섬은 manifest.json에 기록합니다. 데이터 배열 순서와 ID는 학습 기록에 연결됩니다. 이미 배포한 단어의 순서를 바꾸지 말고 새 항목은 뒤에 추가해야 합니다.

위 라이선스는 해당 확장 데이터에 적용됩니다. 사이트 코드, Supabase SDK, 원래 작성한 수업, 생성 영상 및 YouTube 영상은 각자의 출처와 이용 조건을 따릅니다. YouTube 배경음악은 공식 플레이어로 연결하며 음원 파일을 다운로드하거나 재배포하지 않습니다.
